# Future Financial Reports Demonstration

An interactive academic research prototype for an **Agentic Financial Information Ecosystem**.

## Demonstration features

- Role-based access for investors, tax authorities, auditors, corporate management, and regulators
- Explainable financial metrics, calculations, assumptions, and limitations
- Data lineage and evidence provenance visualization
- External intelligence integration with explicit uncertainty labels
- Financial restatement, authorization, and audit-support scenarios

All figures, identity checks, evidence records, and external indicators are simulated for research demonstration purposes.
